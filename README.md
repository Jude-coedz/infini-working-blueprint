# Infini Working Blueprint

A speculative interactive Discovery Sprint deliverable built for a conversation with Infini AI Solutions.

The prototype demonstrates a possible bridge between discovery and a production Build Partnership: prioritise the opportunity, model the proposed workflow, run a thin functional simulation, then separate validated behaviour from unresolved production dependencies.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Motion

## Run locally

```bash
npm install
npm run dev
```

Open `http://127.0.0.1:43128`.

## Deploy

This project needs no environment variables or backend services. Push the folder to a GitHub repository and import that repository into Vercel using the default Next.js settings.

## Demo path

1. Prioritise — inspect and select the proposed opportunity.
2. Model — click workflow nodes to inspect system/human boundaries.
3. Simulate — click **Process update** and watch the operational trace complete.
4. Build readiness — review what the thin slice validated and what remains open.

## Important

The prototype uses public information from Infini AI Solutions' fleet logistics case study plus clearly labelled representative assumptions. It is not presented as an existing Infini service or a reconstruction of confidential client systems.
